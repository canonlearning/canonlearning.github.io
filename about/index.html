About the Project

What is Canon Learning?

A course kit in a box for teaching STEM.

A kit is everything a teacher needs to run a course: a short reading for each lesson, built around interactive visuals and animations; a slide deck for each class; and practice problems with worked solutions.

The reading has as little text as it can and as many visuals as it needs. All of it is free and open, and a teacher can change any part of it. The first kit is Probability 1.

What’s the difference between Canon Learning and OpenStax?

OpenStax publishes textbooks. Canon Learning publishes courses.

OpenStax books are free, peer reviewed, and openly licensed, and they cover far more subjects than this project does. A book is long-form text with static figures. The slides and answer guides that come with it sit behind a verified instructor account, and graded homework runs on partner platforms, many of them paid.

A Canon kit starts from the other end. The lesson is built around visuals a student can run and change, with a few paragraphs between them. The slides use different examples from the reading, so class is not the book read aloud. Every solution is public, because the grade is meant to come from paper quizzes in class and not from homework.

Why does STEM education need this?

Because AI is breaking the classroom.

LLMs have made explanations free and homework answers free. A student can now hand in a correct problem set without understanding a line of it, so homework has stopped measuring anything, and a grade built on it means little.

More explanation is not the fix, because explanation is the part that became free. The fix is a course worth showing up for, where the ideas can be seen and changed, and proof of learning on paper, where a model cannot do the work for the student.

What is the long-term goal?

High quality course materials that are easy to edit, and that a student or a teacher can make their own.

Everything here is Markdown, a plain text file. It opens in any editor, and it is not locked into a web platform, or into Microsoft or Google. Anyone can copy a course, change it, and keep it.

The opinionated stance of this project is that learning needs to be less online and more on paper. A subject is best learned by writing out practice problems by hand, and most of what is sold to classrooms is moving the other way. The hope is that with a full, high quality course here for free, fewer people will reach for the online platforms, and more of the work will go back to paper.

Why minimal text and maximum visuals?

Because text is the part every student already has.

Assume every student is using an LLM. It will explain any idea in as many words as they want, with a rough picture at best. This site is complementary to that: it is where the polished, interactive visuals are, the ones that hammer home an idea better than a page of text can.

A paragraph can say that a test result changes a probability. A visual sorts 1000 people one by one and lets the student change how common the condition is and watch the answer move. Building one takes days, and a teacher preparing three classes a week does not have that time. They are built once here, checked, and given to every teacher.

The slides get the same treatment. A deck has its own drawings and its own examples, made to be read from the back of a room and stepped through while the teacher talks, so the reading and the class complement each other and do not repeat each other.

Is Canon Learning open source?

Yes, all of it, with no open core. This includes:

  • The lessons, slide decks, problems, and worked solutions of each course, such as Probability 1 (CC BY 4.0)
  • The interactive visuals and slide drawings inside a course (MIT)
  • The engine that builds a folder of Markdown into a course site and its decks (MIT)
  • This site, what you’re reading now

CC BY allows commercial reuse with credit. There are no exceptions: no instructor edition, no private answer key, and no closed service behind the site.

Is there a hosted version?

Yes. This site is the hosted version, and it needs no account. Read a lesson, present a deck, or print either one.

There is no login because a course does not need to know who is reading it. If you want a copy you control, fork the course on GitHub and it publishes itself with GitHub Pages at no cost. A course is a folder of static files, so it also runs from a school web server or a USB drive.

Do I have to adopt the whole course?

No. A kit is designed to be used in pieces or whole.

The smallest use is one visual. Open a lesson, put the visual on the projector, and use it in a class that otherwise follows your own notes and textbook. The next step up is assigning one lesson as the reading for a week, or teaching one class from its deck.

The largest use is running the course from the kit: the readings in order, a deck for each class, the problems as practice, and your own paper quizzes for the grade. Teachers who go that far should fork the course, so the order, notation, and examples can be changed to fit the syllabus.

Does it work with an LMS?

Canon Learning does not currently support LMS integration, and it is not a platform. It records nothing about a student.

If enough demand arises, a natural extension is an open source, self-hostable system that lets a school keep its student data on its own servers.

The Model

How is this project organized and funded?

Canon Learning was started by an individual, Ethan Boos, who writes the courses and maintains the engine. It is a side project, with no investors expecting a return.

Plainly, it does not make money by selling the course. Income pays for the author’s time, never for access. In rough order of expected size:

  • Grants for open educational resources, from federal programs, foundations, and state programs that pay faculty to replace paid textbooks
  • Commissioned courses: a department, company, or foundation pays for the next course, and it ships open
  • Help for schools: adapting a course to a syllabus or exam format, and training teachers to run a paper-first class
  • Sponsorship and print: sponsors cover running costs, and printed workbooks sell at a margin while the PDFs stay free

Teachers have no budget, so the money comes from departments, schools, and funders. This is not a good way to get rich. It is a way to keep a course open and maintained.

Why isn’t there an instructor edition or a paid plan?

Selling access would create a conflict of interest between the course and the business.

Publishers earn from an access code bought by each student, each term. That only works if the material is gated and the class cannot easily leave, so the answers go behind an instructor login and the homework goes on a platform the school does not control.

The goal here is the opposite: a kit that is as easy as possible to take and leave. A fork is a complete copy, and it keeps working if this site disappears.
