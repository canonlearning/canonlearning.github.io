About the project

What is Canon Learning?

A set of open courses, each complete enough to teach from. A course has readings built around interactive visuals, a slide deck for each lesson, and practice problems with worked solutions.

The first course is Probability 1. It is being written now, and one lesson is published.

Is it free? Is it open source?

Yes to both.

  • Course content (lessons, slides, problems, solutions) is CC BY 4.0: anyone can copy, change, and reuse it with credit, including commercially.
  • The engine that builds a course into a site is MIT, and so is the code inside a course.
  • Nothing is behind a login, and nothing open moves behind a paywall later.

Can I use a course on my own?

Yes. A course needs no account and no teacher. Read a lesson, work the problems on paper, then open the worked solutions.

I teach this subject. How do I use it in my class?

Teach from it as it is, or fork it. Each lesson page links to its slides and to the Markdown files behind the page and the slides.

  • To use it unchanged, assign the reading and present the slides from the site.
  • To change it, fork the course on GitHub and edit the Markdown files. The fork builds a site of its own.

Why paper and pencil?

Because any take-home answer can now be produced by an LLM. Homework here is ungraded practice done by hand. The grade comes from short paper quizzes in class, which a teacher writes.

Why are there no quizzes?

Everything published is public, solutions included. A published quiz would not measure anything, so a course publishes practice problems only. A teacher writes a graded quiz by changing those problems, and keeps it private.

Does it use AI?

Not when a student uses it. A course is a static site with no chatbot and no model behind it. An LLM helps the author draft visuals and problems, and a person checks each one before it is published.

Are there accounts, grades, or student tracking?

No. A course stores no student data. Grades and rosters belong to a school, so they are planned as a separate, open, self-hosted piece of software. It is not built, and it waits until people are using the courses.

How is the project organized and funded?

It is a side project with one author, Ethan Boos. There is no company selling access to it. Possible income is grants, commissioned courses, and paid help for schools, never access to a course.

Comparisons

Why would I use this instead of a textbook?

A course is interactive and free to read, and it comes with the slides and the problems a teacher needs to run a class.

Why would I use this instead of an online homework system?

Those systems grade take-home answers, which an LLM can now produce. Here homework is practice and the grade is on paper.

Why would I use this instead of a chatbot?

The explanations and worked solutions are written and checked by a person, in one order, with one notation. A chatbot can still help a student who is stuck.

Why would I use this instead of videos?

A video gives intuition for one idea. This is a full course a teacher can run, with practice for every lesson.
